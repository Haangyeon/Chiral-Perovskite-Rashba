# Structural models used in this work

All files are VASP POSCAR/CONTCAR format with **fractional (Direct) coordinates**.

**Naming note.** The tables below quote the original project-tree file names for provenance. The
files themselves are shipped under normalised names; the correspondence is:

| Name quoted below | File shipped in this archive |
|-------------------|------------------------------|
| `S_48185_POSCAR` | `POSCAR_S_static_SOC_input` |
| `Rstar_POSCAR` | `POSCAR_Rstar_inversion_generated` |
| `POSCAR_Rac_static` | `POSCAR_Rac_static_SOC_input` |
| `S_P2_1_symmetrized_POSCAR` | `POSCAR_S_P21_symmetrized` |
| `Rac_P2_1_c_symmetrized_POSCAR` | `POSCAR_Rac_P21_c_symmetrized` |
| `R_screening_CONTCAR` | `POSCAR_R_screening_PBE` |

Three distinct sets of structures are provided, matching the manuscript provenance description:

## 1. Actual static SOC / low-k calculation inputs (SHA256 match the `kpoint_validation.json` files in `input/supplement/02_kpoints_mapping/`)

| File | System | SHA256 (poscar_sha256 in validation JSON) |
|------|--------|--------------------------------------------|
| `S_48185_POSCAR` | S — SOC-SCF and 441-point NSCF input | `4863aed...` |
| `Rstar_POSCAR` | R* — inversion-generated mirror structure (same NSCF grid) | `8ebb4ae...` |
| `POSCAR_Rac_static` | Rac — SOC-SCF and 441-point NSCF input | `76baf69...` |

`Rstar_POSCAR` was generated by exact Cartesian origin inversion of the frozen S structure
(`S_48185_POSCAR`): for every atom, `r -> -r`, followed by wrapping into the same unit cell
(equivalent to a uniform lattice translation); the S and R* files therefore form a strict
inversion pair (verified: maximum deviation from exact inversion is a uniform lattice vector).

## 2. Relaxation / symmetrization models (final PBE-D3(BJ) relaxed structures projected onto the target space group)

| File | System | Notes |
|------|--------|-------|
| `S_P2_1_symmetrized_POSCAR` | S, P2_1 (#4) | G-SYM accepted candidate; lattice a=8.6198 b=7.9248 c=16.3334 A, beta=103.025 deg |
| `Rac_P2_1_c_symmetrized_POSCAR` | Rac, P2_1/c (#14) | G-SYM accepted candidate; lattice a=16.1935 b=7.8753 c=8.7333 A, beta=103.978 deg |

These are the symmetrized relaxation outputs; the static SOC/low-k calculations were run on the
frozen inputs of set 1, which share the same lattice.

## 3. Screening-level structure (PBE, no dispersion correction; listed in Table 1 for reference)

| File | System | Notes |
|------|--------|-------|
| `R_screening_CONTCAR` | Independently relaxed R (PBE screening workflow) | Used only for reference in Table 1; not used in the quantitative analysis |

The experimental single-crystal XRD structures of Liu et al. (Sci. Adv. 9, eadh5083, 2023) are
the construction source of the initial models; their lattice parameters are listed in Table 1 of
the manuscript. The band-overview figure (Fig. 3) shows an earlier D3 validation branch (S, R, and
Rac each independently D3-relaxed); those intermediate structures were superseded by the final
branch above and are not redistributed here.
